# 章节点击自动转换和播放功能

## 功能说明

点击章节时，系统会：
1. **只转换当前章节** - 快速完成，立即可以播放
2. **自动开始播放** - 当前章节转换完成后立即开始播放
3. **后台转换后续章节** - 播放的同时继续转换后续章节

## 工作流程

```
点击章节
    ↓
检查当前章节是否已转换
    ↓
[未转换] → 开始转换当前章节
    ↓
当前章节转换完成 → 立即开始播放
    ↓
后台继续转换后续章节
```

## 技术实现

### 1. TTS Worker 章节模式

**文件**: `novel_reader/gui/workers/tts_worker.py`

```python
TTSWorker(
    book_id=5,
    start_chunk=21,
    chapter_mode=True  # 章节模式
)
```

**章节模式特点**：
- 快速转换当前章节
- 发送 `chapter_finished` 信号
- 继续后台转换后续章节

### 2. 信号流程

```
TTSWorker
    ├─ progress(current, total)      # 进度更新
    ├─ log(message)                   # 日志消息
    ├─ chapter_finished(end, next)    # 当前章节完成
    ├─ finished()                     # 全部完成
    └─ error(error_msg)               # 错误
```

### 3. 主窗口处理

**文件**: `novel_reader/gui/main_window.py`

```python
_on_chapter_selected(start_chunk):
    # 检查当前章节是否已转换
    if chapter_has_audio:
        # 直接播放
        _play_from_chunk(start_chunk)
    else:
        # 转换并自动播放
        _convert_chapter_and_play(book_id, start_chunk)

_on_chapter_tts_finished(chapter_end, next_start):
    # 当前章节转换完成
    # 立即开始播放
    _play_from_chunk(start_chunk)
```

## 用户体验

### 场景一：首次点击章节

```
1. 点击"第一章"
2. 系统显示：正在转换当前章节...
3. 转换完成，立即开始播放
4. 后台继续转换第二章、第三章...
5. 播放完第一章后，自动播放第二章（已转换完成）
```

### 场景二：点击已转换的章节

```
1. 点击"第二章"（已转换）
2. 立即开始播放，无需等待
```

### 场景三：双击章节

```
1. 双击"第三章"
2. 如果未转换 → 自动转换并播放
3. 如果已转换 → 直接播放
```

## 配置选项

### 默认行为

```python
# 点击章节
_on_chapter_selected(start_chunk):
    # 自动转换并播放
```

### 自定义行为

如果您想修改为只转换不自动播放：

```python
# 注释掉自动播放部分
@Slot(int, int)
def _on_chapter_tts_finished(self, chapter_end: int, next_start: int):
    self.tts_widget.add_log(f"✓ 当前章节转换完成！")
    # self._play_from_chunk(self._pending_play_chunk)  # 不自动播放
```

## 性能优化

### 转换速度

- **当前章节**：优先转换，快速可用
- **后续章节**：后台低优先级转换

### 内存管理

- 已转换的 chunk 会跳过
- 支持断点续传

### 进度显示

```
进度条: [████████░░░░░] 50/749 (7%)
状态: 正在转换当前章节...
```

## 与其他功能的集成

### 播放控制

- 播放器会自动使用转换完成的音频
- 支持暂停、停止、跳转

### 书签

- 可以在播放过程中添加书签
- 书签会在播放进度更新后正确保存

### TTS 控件

- 实时显示转换进度
- 显示转换日志
- 可手动停止转换

## 常见问题

### Q: 为什么点击章节后没有立即播放？

A: 需要等待当前章节转换完成。转换速度取决于：
- CPU 性能
- 模型大小
- 章节长度

### Q: 能否同时转换多个章节？

A: 当前版本支持：
- 前台转换：当前章节
- 后台转换：后续章节

### Q: 如何取消正在进行的转换？

A: 在 TTS 日志区域可以看到转换状态。停止转换功能已在代码中实现：
```python
tts_worker.stop()
```

## 已知限制

1. **单任务转换** - 同时只能转换一本书
2. **顺序转换** - 按章节顺序转换，不支持随机顺序
3. **不可暂停** - 转换一旦开始，只能完成或取消
