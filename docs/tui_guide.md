# TUI 界面使用指南

## 启动 TUI

```bash
# 方法 1: 使用模块方式
python -m novel_reader

# 方法 2: 使用示例脚本
python example_tui.py
```

## 界面布局

## 快捷键

| 按键 | 功能 |
|------|------|
| `←` / `h` | 移动到左侧面板 |
| `→` / `l` | 移动到右侧面板 |
| `↑` / `k` | 上一行 |
| `↓` / `j` | 下一行 |
| `Enter` | 播放选中的书籍 |
| `q` | 退出程序 |

## 功能说明

### 书籍列表（左侧）
- 显示所有已导入的书籍
- 显示当前播放进度（current_chunk / 总chunk数）
- 选择书籍后自动加载章节和书签

### 章节列表（中间）
- 显示选中书籍的章节
- 显示每个章节对应的 chunk 起始位置
- 可用于快速定位章节

### 书签列表（右侧）
- 显示选中书籍的书签
- 显示书签位置（chunk ID）和笔记
- 可用于快速跳转到重要位置

## 播放流程

1. 在书籍列表中选择要播放的书籍
2. 按 `Enter` 开始播放
3. TUI 会退出，在终端中显示播放进度
4. 按 `Ctrl+C` 可停止播放
5. 播放进度会自动保存

## 数据同步

- 书籍、章节、书签数据实时从 SQLite 读取
- 播放进度实时更新到数据库
- 支持 TUI 和命令行混合使用

## 注意事项

- 首次使用请先导入书籍：`python -c "from novel_reader.core import import_book; import_book('your_novel.txt')"`
- 播放前需要先生成音频（使用 TTS 模块）
- 确保 mpv 已正确安装
