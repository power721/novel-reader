# GUI 界面使用指南

## 启动方式

### 方法 1: 使用命令行参数
```bash
# 启动 GUI
python -m novel_reader --gui

# 启动 TUI（默认）
python -m novel_reader
```

### 方法 2: 使用启动脚本
```bash
python example_gui.py
```

## 系统要求

### Linux
```bash
# Ubuntu/Debian
sudo apt install python3-tk

# Arch Linux
sudo pacman -S tk

# Fedora
sudo dnf install python3-tkinter
```

### Windows/macOS
Tkinter 通常随 Python 一起安装，无需额外配置。

## 功能说明

### 菜单栏
- **文件** → 导入书籍、退出
- **帮助** → 关于

### 书籍列表（左侧）
- 显示所有已导入的书籍
- 显示当前播放进度
- 单击选择，双击播放

### 章节列表（中间）
- 显示选中书籍的章节
- 显示每个章节对应的 chunk 起始位置
- 双击从该章节开始播放

### 书签列表（右侧）
- 显示选中书籍的书签
- 显示书签位置和笔记
- 双击从书签位置播放
- [添加书签] - 在当前进度添加书签
- [删除书签] - 删除选中的书签

### TTS 转换区域
- **转换整本书** - 将整本书转换为音频
- **转换选中章节** - 转换选中的章节（开发中）
- **进度条** - 显示转换进度
- **日志** - 显示转换过程信息

### 播放控制区域
- **▶ 播放** - 从当前进度开始播放
- **⏸ 暂停** - 暂停播放
- **⏹ 停止** - 停止播放
- **进度条** - 显示播放进度

### 状态栏
- 显示当前状态和提示信息

## 交互方式

### 鼠标操作
- **单击** - 选择项目
- **双击** - 播放（书籍/章节/书签）
- **按钮** - 执行对应操作

### 快捷操作
- 导入书籍：文件 → 导入书籍
- 播放书籍：双击书籍列表项
- 从章节播放：双击章节列表项
- 从书签播放：双击书签列表项
- 添加书签：选中书籍后点击 [添加书签]

## 后台任务

### 播放
- 播放在后台线程运行，不阻塞 GUI
- 可以同时浏览其他书籍

### TTS 转换
- 转换在后台线程运行
- 实时显示转换进度和日志
- 支持取消（开发中）

## 注意事项

1. **首次使用** - 请先导入书籍：文件 → 导入书籍
2. **播放前** - 确保已生成音频（使用 TTS 转换）
3. **mpv 要求** - 确保系统已安装 mpv 播放器
4. **Piper 要求** - TTS 转换需要安装 Piper

## 故障排除

### Tkinter 未安装
```bash
# Linux
sudo apt install python3-tk
```

### 播放失败
- 检查 mpv 是否安装
- 检查音频文件是否存在
- 查看 TTS 转换日志

### TTS 转换失败
- 检查 Piper 是否安装
- 检查模型文件是否存在
- 查看转换日志获取详细错误信息
